# Web Application Exercise

A little exercise to build a web application following an agile development process. See the [instructions](instructions.md) for more detail.

## Product vision statement

A music-tracking platform that helps music fans organize their listening history, rate and review albums, build a wishlist of albums to hear, and discover new music.

## User stories

[View project issues and user stories](https://github.com/software-students-fall2026/web-app-exercise-kapas/issues)

## Steps necessary to run the software

1. Get MongoDB credentials and create `.env` file (see `env.example`)
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python3 app/app.py`
